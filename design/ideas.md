# Ideias de design

Use este arquivo para registrar as decisoes visuais do projeto antes e durante a implementacao.

## Direcao visual

- Interface moderna, tecnologica e arredondada.
- Usar azul-marinho escuro, branco e gradiente roxo/rosa.
- Usar espaco em branco para manter a leitura organizada.
- Usar Poppins como a unica familia tipografica do site.

## Paleta inicial

- Fundo: `#f7f4ef`
- Superficie: `#ffffff`
- Texto principal: `#20211f`
- Texto secundario: `#77766f`
- Bordas: `#e5dfd5`
- Destaque: `#e4684f`

As variaveis estao em `src/styles/global.css` e podem ser ajustadas em um unico lugar.

## Tipografia base

- Familia unica: `Poppins`.
- Titulos principais: peso `800`, tamanho `42-52px`, `line-height: 1.15`, `letter-spacing: -1.5px`, cor `#FFFFFF`.
- Titulos de secao: peso `600/700`, tamanho `32-38px`, `letter-spacing: -0.8px`.
- Subtitulos: peso `500/600`, tamanho `20-24px`.
- Texto normal: peso `400`, tamanho `15-17px`, `line-height: 1.7`, cor `#D5D5E5`.
- Informacoes secundarias: peso `300`, tamanho `12-14px`, cor `#999BAD`.
- Botoes: peso `600/700`, tamanho `14-16px`, `padding: 11px 24px`, `border-radius: 30px`, sem borda.
- Palavras importantes podem usar o gradiente roxo/rosa com `background-clip: text`.

## Cores tipograficas e botoes

- Fundo principal: `#0D1224`.
- Fundo secundario: `#11162B`.
- Elementos principais: `#FFFFFF`.
- Texto normal: `#D5D5E5`.
- Texto secundario: `#999BAD`.
- Gradiente de destaque: `linear-gradient(90deg, #9B32FF, #FF3F91)`.
- Hover dos botoes: `transform: translateY(-2px)` com sombra roxa.

## Componentes para criar

- Navbar responsiva
- Hero da pagina inicial
- Secao de projetos
- Cards de projeto
- Rodape
- Botoes primario e secundario

## Experiencia e responsividade

- Priorizar navegacao simples e leitura rapida.
- Garantir que botoes e links tenham estados de foco visiveis.
- Projetar primeiro a estrutura para telas menores e expandir para desktop.
- Evitar elementos que dependam apenas de hover para comunicar informacao.
